How I work

Three things I believe about product.

Go see it yourself

Secondhand problems produce secondhand solutions. If I can stand where the user stands and count what actually happens, I do that before I write anything down.

Name what you won't build

Anyone can add features. The judgment is in the refusals — and in saying out loud which metric would prove the idea wrong.

Label the guesses

Every proposal rests on assumptions. Writing them down as assumptions is the difference between a plan you can test and a plan you can only defend.
